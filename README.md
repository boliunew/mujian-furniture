# 🪵 Mujian Furniture

美国家具网店 + 发货管理后台。Flask + SQLite，付款走 Stripe Checkout。

| 页面 | 地址 | 说明 |
|---|---|---|
| 🛍️ 商店 | `/` | 顾客选家具、看 360° 旋转图、结账 |
| 🧭 后台 | `/admin.html` | 订单、发货、打印、商品、360 图（中文界面） |
| 📅 预约送货 | `/schedule.html?o=…&t=…` | 顾客自己选卡派送货日期和时段（链接在确认页和邮件里） |
| 🧾 打印 | `/print.html` | 装箱单、4×6 地址标签、BOL 提单、司机单，由后台打开 |

## 🌐 三种语言

商店、预约送货页、后台、打印页都支持 **中文 / English / Español**，右上角 🌐 切换，浏览器会记住；第一次打开按系统语言自动选（后台默认中文，商店默认英文）。

- 商品名和材质可以在后台分别填中文、西班牙语，没填就显示英文
- 顾客用哪种语言下单，Stripe 付款页、预约链接、预约确认、送货提醒、发货通知邮件就用哪种语言
- 托盘标签、BOL 提单、司机单是给美国司机和承运商的单据，保持英文
- 翻译表在 `tools/i18n/`，改完运行 `python tools/i18n/build_i18n.py` 生成 `public/i18n.js`

## ✨ 功能

**📦 订单**
- 状态流转：🟠 待发货 → 🚚 已发货 → ✅ 已送达，也可以取消（库存自动退回）
- 填快递公司和单号（USPS / UPS / FedEx / 物流专车），自动生成物流查询链接
- 标记已发货时自动给顾客发通知邮件（需配置 SMTP，没配置就只记录）
- 每笔订单都有操作记录、后台备注、一键复制地址
- 「🧪 生成测试订单」：不用付款也能模拟一笔真实订单

**🚛 卡派（大件）**
- 商品分「🚛 卡派」和「📦 快递」两种，订单里只要有一件大件就按卡派走
- 结账时顾客选服务等级：门口（尾板卸货）/ 送进门 / 白手套进屋安装
- 收货 ZIP 在本地列表里 → 🚚 本地车队；其他 → 🚛 LTL 承运商。订单里可以手动改
- 付款后顾客收到预约链接，自己选日期和时段，填房屋类型、楼层、电梯、尾板、门禁码等；送货前一天截止时间前可以自己改约
- 本地车队每个时段有单数上限，约满了顾客就选不了；LTL 选的是「希望送达日期」，承运商会再电话确认
- 卡派状态：📅 待预约 → 🗓️ 已预约 → 📦 已装车/已提货 → 🛣️ 运输中 → 🚚 派送中 → ✅ 已签收（还有 ⚠️ 异常），会自动同步订单的已发货/已送达
- 🗓️ 送货日历：按天看每个时段的预约和剩余名额、待预约名单，一键打印某辆车的司机单或当天所有 BOL
- 本地单分配车辆和站序；LTL 单填承运商、PRO 单号、提货日期、托盘数、重量、Class
- 商品可以填包装重量和箱子尺寸，后台按 2025 NMFC 13 级密度表估算货物等级（以承运商核定为准）
- 📧 邮件：付款后发预约链接、预约/改约确认、送货前一天提醒（`python server.py reminders` 每天跑一次，或后台点按钮）
- ⚙️ 设置：送货时段、每段单数、哪些天送、最早/最晚可约、改约截止时间、节假日、本地 ZIP、车辆

**🏬 库存与盘点（多仓库）**
- 每个仓库分别记「在库」（货架上的实物）和「占用」（已付款、还没发货的订单），可卖 = 在库 − 占用
- 勾了「给顾客发货」的仓库，库存才算进商店的可卖数量；展厅这类地方可以只放样品
- 顾客下单时自动从第一个能发齐的仓库发货，待发货订单可以手动换仓库；真正发货（快递发货 / 卡派装车）时才从在库里扣
- 每件商品有 SKU 条码和库位（例如 A-03），可以打印 2.25×1.25 英寸条码标签
- 📋 盘点：整仓 / 按分类 / 挑选商品抽盘，可选盲盘（盘点时看不到账面数）；扫码枪或手机摄像头扫一下 +1，也可以手动填；提交审核 → 填差异原因 → 确认过账自动调整库存；可打印纸质盘点表
- 盘点开单时记下账面数，过账时按「实盘 − 开单时账面」调整，所以盘点过程中有订单发货也不会被覆盖
- 📥 入库、🔁 调拨（不能调走被订单占用的）、✏️ 单件调整（必须写原因）
- 📒 库存流水：每一次变动都有记录，可按商品、仓库、类型筛选
- 手机摄像头扫码需要 https 网址（部署后或 GitHub Pages 上可以用）

**🏷️ 托盘 / 箱子标签 + 自动打印**
- 订单付款后自动拆成「处理单元」：大件每件一个托盘（后台改托盘数后自动合并），小件每件一个箱子
- 每个托盘/箱子一张 4×6 标签：收货地址和电话、托盘号「1/3」、托盘条码（例如 MJ261104-001-01）、上面每件商品的名字和 SKU 条码、重量、白手套/尾板/楼层标记、车辆站序或承运商 PRO 号和预约日期
- 订单里可以看到每个托盘贴好标签的样子，标签预览和打印出来的一模一样
- 付款后进入「待打印标签」队列，打印后在订单记录里留一条
- **自动打印方式一（任何标签打印机）**：后台订单页打开「🖨️ 自动打印：开」，后台开着时新订单会自动弹出打印。Chrome 加 `--kiosk-printing` 启动，连打印对话框都不弹，直接用默认打印机出纸
- **自动打印方式二（Zebra 等 ZPL 打印机，推荐）**：在仓库电脑上运行 `print_agent.py`，不用开后台，标签直接发到打印机：
  ```bash
  python print_agent.py --test --printer 192.168.1.50                   # 先打一张样张
  python print_agent.py --url https://你的网站 --password 后台密码 --printer 192.168.1.50
  python print_agent.py ... --printer "windows:ZDesigner GK420d"        # USB 打印机（需 pip install pywin32）
  python print_agent.py --test --printer dir:labels --preview           # 没打印机时生成 .zpl 和 PNG 预览
  ```
  Rollo、DYMO 不支持 ZPL，用方式一

**📧 邮件系统**
- 后台「📧 邮件」里填发信设置（SMTP），Gmail / Outlook / Yahoo / SendGrid / Mailgun 一键带出服务器和端口；可以发测试邮件
- 所有邮件先进发件队列，后台线程负责发送，发信慢或失败不会卡住下单；失败自动重试 3 次
- 「📤 发件记录」能看每封邮件的内容、状态和错误原因，可以重新发送
- 员工通知：新订单、待办到期发到员工邮箱（可选中文 / 英文 / 西班牙文）
- 顾客邮件可以整体关掉；`.env` 里的 `SMTP_*` 仍然有效，后台填了就以后台为准
- Gmail 要用「应用专用密码」，不能用平时的登录密码

**✅ 待办和订单备注**
- 订单备注可以记多条，每条带时间；每条可选「印在标签上」，也可以设提醒时间（到点生成待办，可发邮件）
- 「✅ 待办」页：按已过期 / 24 小时内 / 以后 / 没有到期时间分组，可关联订单、设到期时间、发邮件提醒、打印到标签
- 右上角 🔔 显示到期的待办数，后台开着时到期会弹出提示，也可以打开浏览器通知
- 系统自动待办（处理好会自己关掉）：卡派订单付款两天没预约、付款两小时没打印标签、LTL 两天内送货还没有 PRO 单号
- 每分钟自动检查一次；也可以用 `python server.py reminders` 放进定时任务

**🏷️ 关联信息印到单据上**
- 托盘标签、装箱单、司机单、BOL 都会印出：顾客填的送货备注 + 勾了「印在标签上」的订单备注 + 没完成且勾了打印的待办（☐ 开头）
- Zebra 打印程序同样会印这些；中文或西语备注要在打印机上装字体，然后加 `--font E:SIMSUN.TTF`

**🖨️ 打印**
- 🧾 装箱单：Letter 尺寸，普通打印机，放进箱子给顾客
- 🏷️ 地址标签：4×6 英寸，带订单号条码，适合 Rollo / Zebra 等热敏标签打印机
- 📄 BOL 提单：Straight Bill of Lading 短式，含托盘、件数、重量、Class、附加服务（尾板/住宅/预约/送进屋）、三方签字栏
- 🗒️ 司机单：按时段和站序排好，含电话、地址、楼层电梯、门禁备注、签收栏
- 可以勾选多个订单批量打印
- ⚠️ 地址标签**不含邮资**。邮资在 USPS / Pirate Ship / UPS 网站购买

**🪑 商品**
- 新增、修改、下架、删除商品；改价格和库存
- 上传主图（自动转成 JPG、压缩、修正手机照片方向）
- 库存在付款后自动扣减，库存不足时不能下单，商店会显示 "Only N left" / "Sold out"

**🔄 360° 旋转图**
1. 家具放在转盘中央，手机固定在三脚架上不动
2. 每转 10°–15° 拍一张，一圈 24–36 张。白墙或纯色背景，光线均匀
3. 后台 → 商品 → 选择这一组照片。浏览器会自动按文件名排序、找出家具位置、统一裁切居中、把背景处理成白色
4. 先拖动预览效果，满意再点保存。商店商品页就能拖动旋转

支持 JPG / PNG / WebP。iPhone 的 HEIC 照片要先导出成 JPG（相机设置 → 格式 → 兼容性最佳）。

## 🚀 本地运行

```bash
pip install -r requirements.txt
cp .env.example .env          # Windows: copy .env.example .env
```

打开 `.env`，至少设置 `ADMIN_PASSWORD`。然后：

```bash
python server.py
```

- 商店：http://localhost:4242
- 后台：http://localhost:4242/admin.html

**没填 Stripe 密钥时是演示模式**：商店里点 Checkout 会直接生成一笔已付款的测试订单，适合先熟悉后台流程。

### 💳 接上 Stripe 测试付款

1. 注册 https://dashboard.stripe.com/register ，Developers → API keys 复制 `sk_test_...` 填到 `STRIPE_SECRET_KEY`
2. 安装 Stripe CLI（https://docs.stripe.com/stripe-cli ），运行：
   ```bash
   stripe login
   stripe listen --forward-to localhost:4242/webhook
   ```
   把它打印的 `whsec_...` 填到 `STRIPE_WEBHOOK_SECRET`，重启 `server.py`
3. 结账时用测试卡 `4242 4242 4242 4242`，有效期填未来任意日期，CVC 任意 3 位

## 🔐 安全设计

- 价格和库存只以服务器数据库为准，浏览器只传商品编号和数量
- 卡号只在 Stripe 的页面输入，服务器接触不到
- 订单只有收到**签名验证通过**的 Stripe Webhook 才算已付款
- 后台用密码登录，登录状态存在签名的 HttpOnly Cookie 里
- 上传的图片都经过 Pillow 重新编码，非图片文件会被拒绝

## 🌐 上线

1. **主机**：Render / Railway / Fly.io，启动命令 `gunicorn server:app`
2. **数据持久化**：数据库 `shop.db` 和图片 `uploads/` 需要放在持久磁盘上（Render 要加 Disk，挂载后用 `DB_PATH`、`UPLOAD_DIR` 指过去），否则每次重新部署会丢数据
3. **环境变量**：`ADMIN_PASSWORD` 设强密码，`SECRET_KEY` 设随机字符串，`DOMAIN` 改成 `https://你的域名`
4. **Stripe**：激活账户，换成 `sk_live_...`；Dashboard → Webhooks 添加 `https://你的域名/webhook`，事件选 `checkout.session.completed` 和 `checkout.session.expired`
5. **销售税**：开通 Stripe Tax，去掉 `server.py` 里 `automatic_tax` 那行的注释
6. **邮件**：填 `SMTP_*`。Gmail 用 `smtp.gmail.com`、端口 587、应用专用密码
7. **送货提醒**：每天定时跑一次 `python server.py reminders`（Render 用 Cron Job，或者服务器上的 crontab），也可以每天在后台「送货」里点「📧 发送明天的提醒」
8. 补上退货政策、隐私政策、联系方式页面
